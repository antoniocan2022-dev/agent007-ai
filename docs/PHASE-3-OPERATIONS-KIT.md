# Phase 3 — Small Business Operations Kit

Canonical flow: `intake → observe → map → diagnose → prioritize → design → authorize → implement → measure → learn`.

Leader: `SMB_OPERATIONS_LEADER`.

The unit reuses the Phase 1 Commercial Control Plane. It does not create a second CRM, billing ledger, event ledger, workflow ledger, evidence ledger, or authority system.

Core controls: process-stage validation, bounded automation-feasibility scoring, evidence lineage, idempotent observation persistence, and delegated-authority verification before external workflow activation.

The first domain output is an Operations Plan containing measurable monthly minutes saved, estimated monthly value, expected error reduction, evidence IDs, priority, and blocked external actions.

External provider adapters, production customer messaging, and irreversible financial actions remain outside this phase until their credentials, consent, and delegated-authority contracts are explicitly configured.
