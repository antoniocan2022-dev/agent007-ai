# Phase 4 — Career Command Center

Canonical flow: `profile → discover → organize → prepare → user-approval → submit → track → learn`.

The Career Command Center is user-controlled career assistance. It reuses the Phase 1 Commercial Control Plane for tenant, event, workflow, evidence, billing and authority infrastructure. It does not create automated employment eligibility decisions, candidate-ranking decisions, or autonomous hiring recommendations.

Core capabilities include career-profile organization, job-source organization, skill-gap information, resume customization, ATS preparation, application preparation and tracking, networking support, interview preparation, compensation information, personal-brand support, and career learning.

External application progression requires explicit user approval and is recorded as a commercial event for auditability. Vercel deployment is intentionally outside this phase.
