# Phase 2 — AI Revenue Recovery for Local Businesses

Canonical flow: `intake → measure → score → plan → authorize → execute → measure-outcome → learn`.

Leader: `REVENUE_RECOVERY_LEADER`.

The unit is built on the Phase 1 Commercial Control Plane. It does not introduce a second CRM, billing ledger, event ledger, or authority system.

Core controls: funnel stage ordering, deterministic recovery opportunity scoring, bounded confidence, delegated-authority evaluation before queued work, idempotent events/workflows, and separate outcome records for verified recovered revenue.
