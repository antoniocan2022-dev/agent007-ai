# Five-Phase Hardening

This document records the cross-phase integrity remediation track.

## Canonical rules
- Derived analysis is not verified evidence.
- Portfolio decisions require evidence confidence meeting the CEO Venture Mandate.
- Period counts are based on distinct observation periods, not snapshot count.
- Venture identity cleanup may only remove a reservation owned by the current creation attempt.
- Career external application transitions require a durable owner-approval record.
- Portfolio experiments must remain within CEO spend guardrails.

## Verification
The final hardening branch must pass repository integrity, Venture architecture, TypeScript, autonomy tests, lint, and revenue foundation CI before merge.
